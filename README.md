## 🇮🇷 معرفی فارسی

### ✨ درباره پروژه

**Signal Studio AI** یک پروژه نرم‌افزاری در حال توسعه برای ساخت پادکست‌های تصویری، انیمیشن‌های سه‌بعدی و محتوای آموزشی است.

هدف این پروژه ایجاد محیطی است که کاربران بتوانند بدون نیاز به تسلط کامل بر نرم‌افزارهای پیچیده انیمیشن‌سازی، شخصیت‌های سه‌بعدی را مدیریت کنند، سکانس بسازند، صداگذاری انجام دهند و داستان‌های خود را به تصویر بکشند.

فلسفه طراحی این پروژه از سه ابزار حرفه‌ای الهام گرفته است:

- 🎬 **CapCut:** سادگی، سرعت و تجربه کاربری روان
- 🎨 **Blender:** امکانات و انعطاف‌پذیری ویرایش سه‌بعدی
- 🎞️ **DaVinci Resolve:** مدیریت حرفه‌ای تایم‌لاین و فرآیند تدوین

### 🚀 امکانات پروژه

**🎭 مدیریت شخصیت‌های سه‌بعدی**

- افزودن، حذف و مدیریت شخصیت‌ها
- تنظیم موقعیت، اندازه و وضعیت نمایش
- تعریف رویدادهای انیمیشن روی تایم‌لاین
- زیرساخت کنترل حالات چهره و حرکات بدن

**🎬 مدیریت سکانس‌ها**

- ایجاد و ویرایش سکانس‌های مختلف
- مدیریت ترتیب و مدت‌زمان سکانس‌ها
- کنترل محیط و دوربین
- پیش‌نمایش سه‌بعدی با Three.js

**🎧 ویرایش صدا**

- واردکردن فایل‌های صوتی
- Drag & Drop صدا روی تایم‌لاین
- جابه‌جایی، برش و تقسیم کلیپ‌ها
- ادغام غیرمخرب کلیپ‌های سازگار
- تخصیص گوینده به شخصیت‌ها
- مدیریت چند کلیپ و تنظیمات صوتی

**⏱️ تایم‌لاین یکپارچه**

- نمایش سکانس‌ها، صداها و رویدادهای انیمیشن
- بزرگ‌نمایی و کوچک‌نمایی تایم‌لاین
- مدیریت موقعیت زمانی بر اساس فریم
- Undo / Redo برای عملیات ویرایش صوتی

**🌐 رابط کاربری**

- طراحی فارسی و راست‌به‌چپ (RTL)
- محیط کاری واکنش‌گرا
- ابزارهای وابسته به انتخاب کاربر
- تفکیک تنظیمات ساده و پیشرفته

### 🧠 چشم‌انداز آینده

قابلیت‌هایی که در مسیر توسعه پروژه قرار دارند:

- تولید و پیشنهاد سکانس‌ها با کمک هوش مصنوعی
- انیمیشن طبیعی‌تر چهره، دست‌ها و بدن
- هماهنگ‌سازی دقیق حرکت لب با گفتار (Lip Sync)
- کارگردانی هوشمند و حرکات سینمایی دوربین
- تولید زیرنویس خودکار
- ترکیب هوش مصنوعی با ویرایش دستی
- رندر و خروجی ویدیویی

> **وضعیت توسعه:** پروژه در مرحله توسعه فعال است. برخی امکانات پیاده‌سازی شده‌اند، اما هنوز به آزمایش و تکمیل بیشتر نیاز دارند.

## 🇬🇧 English Overview

### ✨ About the Project

**Signal Studio AI** is an evolving creative application designed for producing animated podcasts, 3D storytelling experiences, and educational visual content.

The goal is to make 3D content creation more accessible by combining an intuitive editing experience with powerful scene management, character animation, audio editing, and future AI-assisted production workflows.

The product's design direction draws inspiration from:

- **CapCut** — Simplicity and intuitive editing
- **Blender** — Flexible 3D scene and character controls
- **DaVinci Resolve** — Professional timeline workflows

### 🚀 Key Features

**🎭 3D Character Management**

- Create and manage scene characters
- Control character position, scale, and visibility
- Timeline-based character action events
- Foundational facial expression and body animation controls

**🎬 Scene Editing**

- Create, organize, and edit scenes
- Manage scene duration and ordering
- Configure scene cameras and environments
- Preview 3D scenes using Three.js

**🎧 Audio Editing**

- Import audio files into scenes
- Drag and drop audio onto the timeline
- Move, trim, split, and manage clips
- Non-destructive merging of compatible clips
- Assign speaker identities to characters
- Manage multiple audio clips

**⏱️ Unified Timeline**

- Scene, audio, speaker, and animation tracks
- Timeline zoom and adaptive ruler
- Frame-based positioning
- Audio editing undo/redo

**🌐 User Experience**

- Persian-first RTL interface
- Responsive workspace
- Context-aware editing controls
- Beginner-friendly and advanced settings

### 🧠 Roadmap

- [ ] AI-assisted scenario and scene generation
- [ ] Advanced procedural character animation
- [ ] Natural facial expressions and body gestures
- [ ] Speech-driven lip synchronization
- [ ] Intelligent cinematic camera direction
- [ ] Automatic subtitle generation
- [ ] AI-assisted editing workflows
- [ ] Video rendering and export

### 🛠️ Technology Stack

| Technology   | Purpose                           |
| ------------ | --------------------------------- |
| Next.js      | Application framework             |
| React        | Interactive user interface        |
| TypeScript   | Type-safe development             |
| Three.js     | 3D rendering and scene management |
| Tailwind CSS | Responsive interface styling      |
| Playwright   | Browser-based end-to-end testing  |

### 🧪 Development & Testing

The project uses a combination of TypeScript validation, ESLint, automated tests, production builds, and Playwright browser tests.

Implementation status and verification results are documented separately to distinguish completed functionality from features requiring further testing.

### 🎯 Project Vision

> **Make 3D storytelling accessible, intuitive, and creatively powerful.**

Signal Studio AI aims to bridge the gap between advanced animation tools and simple content editors, helping creators transform ideas into engaging animated experiences.
